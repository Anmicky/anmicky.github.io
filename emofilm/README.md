# Emo-FilM measurement and reuse map

Live page: https://anmicky.github.io/emofilm/

A self-contained Chinese interactive reading map of the 50 retained measurement items and six studies reusing Emo-FilM. Select a study to highlight its data selections; select an item for its scale endpoints and participant instructions.

## Evidence and attribution

Item groups and instructions: Morgenroth et al. (2025), Scientific Data, DOI 10.1038/s41597-025-04803-5, Supplementary Table 1 (CC BY 4.0). Translations and scale-polarity interpretations are marked as editorial judgments; ambiguous cases and the source table's Bad endpoint error are retained explicitly.

The component-analysis study's detailed methods and numbers are from its openly available 2024 preprint, with the 2026 publication identified separately. Conference abstracts are presented separately from full papers. Source links and interpretation boundaries accompany each study. Checked 2026-10-21.

## Editing

This folder is an independent static page. No build step, external font service, analytics or login is required. All diagram data is embedded in index.html; graph-data.json is a readable parallel export. Keep those two representations consistent when editing. reference.html contains the item atlas and extended paper notes.
