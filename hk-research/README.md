## 内容口径

- QS 2027是大学综合排名；THE Psychology 2026是学科排名，两者均不是实验室排名。
- 研究组用研究线、方法与代表作描述。没有编造实验室序位、录取概率、导师性格或指导质量评分。
- `data.json` 的 `sources` 逐项记录来源类型、阅读深度与核查日期。部分来源为搜索索引、部分论文仅核目录或摘要；未完成逐篇全文精读。
- 未注明年度的招生信号不等于2027名额；校方奖学金入口不等于个人资助保证。CityU神经科学官网本轮403，其正式资格要求保留待核。
- 页面覆盖范围有限，未收集到不代表不存在。公开资料还不足以核定学生培养体验、个人资助、指导投入或毕业去向。

## 文件与运行

`index.html`、`style.css`、`app.js`、`data.json`，无需构建。通过任意静态HTTP服务器预览；直接双击本地HTML可能阻止读取JSON。

比较选择仅存于用户浏览器的localStorage，不上传。无第三方统计、表单提交或外部脚本。英文字体复用站内已有文件，中文使用系统字体。

更正资料时，先更新证据与阅读范围，再更新判断；保留无法核验的部分。
